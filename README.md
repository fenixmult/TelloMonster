# 🤖 TelloMonster

Projeto experimental de robótica baseado no DJI Tello.

A ideia é transformar um drone parado em uma plataforma robótica capaz de **voar, andar, enxergar, ouvir e interagir**, aproveitando o máximo possível do hardware original.

## 🚁 Objetivo

Criar um robô híbrido controlado por Python, com:

- 📷 Câmera do Tello
- 🧭 Sensores e IMU
- 📡 Wi-Fi
- 🚁 Controle de voo
- 🛞 Locomoção terrestre
- 🎤 Comando de voz
- 🔊 Comunicação por áudio
- 🧠 Inteligência artificial
- 🌐 Controle pela internet
- 🏠 Integração com casa inteligente

## 🧪 Projeto experimental

O TelloMonster será desenvolvido passo a passo.

Cada etapa será testada, documentada e publicada no GitHub, blog e vídeos.

## 🗺️ Roadmap

- [ ] Fase 1 — Comunicação Python + Tello
- [ ] Fase 2 — Câmera e vídeo
- [ ] Fase 3 — Telemetria e sensores
- [ ] Fase 4 — Comando de voz
- [ ] Fase 5 — Chassi e rodas
- [ ] Fase 6 — Controle terrestre
- [ ] Fase 7 — Microfone e alto-falante
- [ ] Fase 8 — Visão computacional e IA
- [ ] Fase 9 — Controle pela internet
- [ ] Fase 10 — Integração com Google Home / Smart Life

## 🛠️ Hardware atual

- DJI Tello
- PC Linux
- Python
- Wi-Fi

## 📚 Objetivo do projeto

Aprender e experimentar robótica, programação, visão computacional, automação e inteligência artificial utilizando hardware que já temos.

> O projeto começa simples e evolui através de testes reais.
